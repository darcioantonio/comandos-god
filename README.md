# Comandos GM & GOD - Canary

Site estático com uma lista pesquisável de comandos administrativos do Canary.

## Aviso

Os comandos foram retirados do Canary / Tibia 15. A maioria também funciona em bases Tibia 13, mas alguns podem variar conforme a versão ou modificações do servidor.

Fonte:
https://github.com/opentibiabr/canary

TalkActions:
https://github.com/opentibiabr/canary/tree/main/data/scripts/talkactions

## Deploy no Vercel

O projeto é HTML/CSS/JS puro. Basta importar este repositório no Vercel e fazer o deploy sem configuração de build.
